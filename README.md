## Project Overview

A data analytics project focused on **managing, analyzing, and visualizing personal financial transaction data**.

The project demonstrates an end-to-end workflow using **Excel for data preparation, SQL/MySQL for data storage and analysis, and Power BI for interactive dashboards and reporting**.

---

## Data Analytics Workflow

Raw Financial Data
       ↓
Excel / CSV
       ↓
Data Cleaning & Preparation
       ↓
MySQL Database
       ↓
SQL Analysis
       ↓
Power BI
       ↓
Dashboard & Insights

## Key Business Insights

The dashboard analyzes:

* Total income
* Total expenses
* Remaining balance
* Category-wise spending
* Payment method patterns
* Transaction activity
* Spending trends over time
